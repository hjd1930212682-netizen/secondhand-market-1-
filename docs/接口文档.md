# 闲置集市接口文档

前后端共用这一份。改动接口时先改本文档，再改代码，最后跑一遍第 7 节的核对命令。

- 基础地址：`http://127.0.0.1:8000`
- 共 **30 个** `/api` 接口，分 6 组
- 交互式文档：服务启动后访问 `/docs`（FastAPI 自动生成）

## 1 通用约定

| 项目 | 约定 |
|---|---|
| 请求体 | JSON（`Content-Type: application/json`），图片上传例外为 `multipart/form-data` |
| 鉴权 | 受保护接口带 `Authorization: Bearer <token>`；令牌由登录接口下发，默认有效期 1440 分钟 |
| 列表返回 | `{"items": [...], "total": 0, "page": 1, "size": 12}`，`page` 从 1 开始 |
| 错误返回 | `{"detail": "中文提示"}`，前端直接把 `detail` 弹 toast |
| 时间字段 | ISO 8601 字符串，如 `2026-11-20T10:30:00` |
| 金额字段 | 字符串形式的小数（`decimal(10,2)`），避免浮点误差 |

## 2 错误码

| 状态码 | 含义 | 典型场景 | 前端处理 |
|---|---|---|---|
| 200 | 成功 | 查询、更新成功 | 正常渲染 |
| 201 | 已创建 | 注册、发布商品、下单、发消息、评价、收藏 | 跳转或刷新 |
| 400 | 参数非法 | 字段缺失、价格 ≤ 0、评分超 1~5、状态取值不在枚举内 | 提示具体字段 |
| 401 | 未登录 / 令牌失效 | 未带令牌、令牌过期、账号密码错误 | 清空令牌并跳登录页 |
| 403 | 越权 | 改别人的商品、看别人的订单、买家替卖家确认 | 提示无权操作 |
| 404 | 不存在 | 商品已下架、订单不存在、用户不存在 | 提示并返回列表 |
| 409 | 冲突 | 商品已被抢购、重复收藏、重复评价、非法状态流转、用户名已注册 | 提示后刷新数据 |
| 500 | 服务端异常 | 未预期错误 | 提示稍后重试 |

> 参数校验错误统一返回 400（不是 FastAPI 默认的 422），由 `app/main.py` 的
> `RequestValidationError` 处理器改写，前端只需处理一套错误格式。

## 3 账号与鉴权（4 个）

| 方法 | 路径 | 鉴权 | 参数 | 返回 | 错误 |
|---|---|---|---|---|---|
| POST | `/api/auth/register` | 否 | `username` str必填 3~50、`password` str必填 6~64、`nickname` str必填 | `{id, username, nickname, avatar, credit_score, created_at, phone}` | 400、409 用户名已注册 |
| POST | `/api/auth/login` | 否 | `username`、`password` | `{access_token, token_type:"bearer", user:{...}}` | 400、401 用户名或密码错误 |
| GET | `/api/auth/me` | 是 | 无 | 当前用户资料（含 `phone`） | 401 |
| GET | `/api/users/{id}` | 否 | 路径 `id` int | 公开资料（不含 `phone`） | 404 |

## 4 用户与商品（10 个）

| 方法 | 路径 | 鉴权 | 参数 | 返回 | 错误 |
|---|---|---|---|---|---|
| PUT | `/api/users/me` | 是 | `nickname` 必填、`phone` 可空、`avatar` 可空 | 更新后的本人资料 | 400、401 |
| PUT | `/api/users/me/password` | 是 | `old_password`、`new_password`（6~64） | `{message}` | 400 原密码错误、401 |
| GET | `/api/users/me/goods` | 是 | query `page` 默认1、`size` 默认12 | 商品列表（含已下架、已售） | 401 |
| GET | `/api/categories` | 否 | 无 | `[{id, name, parent_id}]` | — |
| POST | `/api/goods` | 是 | `category_id` int必填、`title` 1~160、`description`、`price` >0、`images` 逗号分隔最多5张 | 新商品（含 `seller_name`、`category_name`） | 400、401、404 分类不存在 |
| PUT | `/api/goods/{id}` | 是 | 同上 | 更新后的商品 | 400、403 非本人、404 |
| PUT | `/api/goods/{id}/status` | 是 | `status` 取 `在售` 或 `已下架` | 更新后的商品 | 400、403、404、409 已售商品不可改 |
| DELETE | `/api/goods/{id}` | 是 | 路径 `id` | 下架后的商品（软删除） | 403、404、409 |
| GET | `/api/goods` | 否 | `keyword`、`category_id`、`sort`（`newest`/`price_asc`/`price_desc`/`hot`）、`page`、`size` | 在售商品列表，`items` 每项含卖家昵称、分类名 | — |
| GET | `/api/goods/{id}` | 否 | 路径 `id` | 商品详情（含卖家头像、信用分），浏览量 +1 | 404 商品不存在或已下架 |

## 5 交易（5 个）

| 方法 | 路径 | 鉴权 | 参数 | 返回 | 错误 |
|---|---|---|---|---|---|
| POST | `/api/orders` | 是 | `goods_id` int必填 | 订单对象 + `available_actions` | 400 买自己的商品、401、404、409 商品已被抢购 |
| GET | `/api/orders` | 是 | `role` 取 `buyer`（默认）或 `seller`、`status` 可选、`page`、`size` | 本人订单列表 | 400 角色不合法 |
| GET | `/api/orders/{id}` | 是 | 路径 `id` | 订单详情 | 403 与订单无关、404 |
| PUT | `/api/orders/{id}/status` | 是 | `to_status` 取值见状态机 | 最新订单 + 新的 `available_actions` | 403 角色越权、404、409 非法流转 |
| POST | `/api/orders/{id}/review` | 是 | `rating` int 1~5、`content` 1~500 | 新评价 | 400 未完成交易、403 非买家、409 已评价 |

订单对象字段：`id`、`order_no`、`goods_id`、`goods_title`、`goods_images`、`buyer_id`、`buyer_name`、
`seller_id`、`seller_name`、`price`、`status`、`created_at`、`finished_at`、`reviewed`、`available_actions`。

`available_actions` 每项：`{label: "确认出售", to_status: "PAID_PENDING", style: "primary"}`，
前端直接渲染按钮，不自行推断状态规则。

## 6 互动（9 个）

| 方法 | 路径 | 鉴权 | 参数 | 返回 | 错误 |
|---|---|---|---|---|---|
| GET | `/api/favorites` | 是 | `page`、`size` | 收藏列表，`items` 每项 `{id, goods:{...}}` | 401 |
| POST | `/api/favorites` | 是 | `goods_id` int必填 | 收藏记录 | 404、409 已收藏 |
| DELETE | `/api/favorites/{goods_id}` | 是 | 路径 `goods_id` | `{message:"已取消收藏"}` | 404 |
| POST | `/api/messages` | 是 | `receiver_id` 必填、`goods_id` 可选、`content` 1~1000 | 新消息 | 400 不能给自己发、404 接收人不存在 |
| GET | `/api/messages` | 是 | `peer_id` 可选（给定时只取与该人会话）、`page`、`size` 默认50 | 消息列表 | 401 |
| PUT | `/api/messages/read` | 是 | `peer_id` int必填 | `{updated: n}` 标记为已读的条数 | 401 |
| GET | `/api/messages/unread-count` | 是 | 无 | `{count: n}` | 401 |
| GET | `/api/goods/{id}/reviews` | 否 | 路径 `id`、`page`、`size` | 该商品的评价列表（含评价人昵称） | 404 |
| GET | `/api/users/{id}/rating` | 否 | 路径 `id` | `{user_id, average, count}` | 404 |

## 7 平台与文件（2 个）

| 方法 | 路径 | 鉴权 | 参数 | 返回 | 错误 |
|---|---|---|---|---|---|
| POST | `/api/upload` | 是 | `multipart/form-data`，字段 `file` | `{"url": "/uploads/xxx.jpg"}` | 400 类型或大小不符、401 |
| GET | `/api/health` | 否 | 无 | `{"status":"ok","database":"connected"}` | 503 数据库不通 |

图片上传限制：JPG / PNG / WebP，单文件 ≤ 5 MB，文件名由服务端重写，避免路径穿越。
`/pages/{page}.html` 由 StaticFiles 提供，不属于 `/api` 接口，故不计入 30 个之内。

## 8 订单状态与接口的对应关系

| 当前状态 | 可调用 `to_status` | 角色 | 按钮文案 |
|---|---|---|---|
| PENDING | PAID_PENDING | 卖家 | 确认出售 |
| PENDING | CANCELLED | 卖家 | 拒绝 |
| PENDING | CANCELLED | 买家 | 撤销订单 |
| PAID_PENDING | COMPLETED | 买家 | 确认收货 |
| PAID_PENDING | CANCELLED | 买家 | 取消订单 |
| COMPLETED | CANCELLED | 买家 | 申请退款 |

共 6 条合法转移，定义在 `app/services/order_state.py`。状态不允许 → 409，角色不对 → 403。

## 9 文档与实现的一致性核对

本文档的路径表由 `app.openapi()` 导出后逐条比对，命令：

```bash
python -c "from app.main import app; s=app.openapi(); print('路径', len(s['paths'])); print('接口', sum(len(v) for v in s['paths'].values()))"
```

正常输出为 `路径 24`、`接口 30`（同一个路径可支持多个方法，如 `/api/goods` 同时有 GET 与 POST）。
接口数与各节表格数量一致：账号 4 + 用户与商品 10 + 交易 5 + 互动 9 + 平台与文件 2 = 30。
若对不上，以命令输出为准并更新本文档。
